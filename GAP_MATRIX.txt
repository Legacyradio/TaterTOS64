_SSL.C — FULL MODULE REPLACEMENT (27 OpenSSL functions)
================================================================================
CPython's _ssl.c wraps OpenSSL. BearSSL has a completely different API.
The entire _ssl.c must be replaced with a BearSSL-backed implementation.

OpenSSL functions used by CPython _ssl.c:
  SSL_CTX_new, SSL_CTX_free, SSL_new, SSL_free
  SSL_connect, SSL_read, SSL_write, SSL_shutdown
  SSL_get_error, SSL_set_fd
  SSL_CTX_use_certificate, SSL_CTX_use_private_key
  SSL_CTX_load_verify_locations, SSL_CTX_set_verify
  SSL_CTX_set_default_verify_paths
  SSL_get_peer_certificate, SSL_get_verify_result
  SSL_CTX_set_cipher_list, SSL_CTX_set_options
  TLS_client_method, TLS_server_method
  X509_new, X509_free, X509_get_subject_name
  ERR_get_error, ERR_error_string
  RAND_bytes, RAND_status
  BIO_new, BIO_free, BIO_read, BIO_write

BearSSL equivalents (mapping):
  br_ssl_client_context     -> SSL_CTX + SSL combined
  br_ssl_engine             -> SSL_read/SSL_write layer
  br_x509_minimal_context   -> certificate verification
  br_ssl_client_init_*      -> TLS_client_method
  br_ssl_engine_sendapp_buf -> SSL_write buffer
  br_ssl_engine_recvapp_buf -> SSL_read buffer
  br_ssl_engine_flush       -> SSL_write flush
  br_x509_trust_anchor      -> X509 trust store

This is Phase 3 work (~500-1000 lines of C). Not a stub — real implementation.

CONCLUSION
================================================================================
The gap is manageable:
- 35 stubs (trivial, no kernel changes, ~2-3 lines each in posix.c)
- 1 disable (pyconfig.h: #undef HAVE_FORK)
- 7 simple implementations (wrap existing syscalls, ~10-20 lines each)
- 7 socket stubs/implementations (trivial)
- 27 OpenSSL→BearSSL mappings (Phase 3, ~500-1000 lines)
- ~12 missing headers (struct definitions + typedefs, no kernel changes)

No new kernel syscalls are strictly required. The 145 existing native
syscalls cover CPython's needs. The work is in the libc/header layer
and the _ssl.c replacement.

Phase 1 audit is complete. Phase 2 can begin.
