blocker:
  Crashpad includes libc++ <uchar.h>, which includes TaterTOS <uchar.h>.
  TaterTOS declared mbrtoc16/c16rtomb/mbrtoc32/c32rtomb with the C keyword
  restrict. In C++ mode, restrict is not a standard keyword and TaterTOS did
  not define it, so the prototypes failed to parse.

classification:
  TaterTOS libc/header C++ compatibility gap.

fix:
  Updated TaterTOS64/src/include/uchar.h to spell the restrict qualifier as
  __restrict in the conversion function prototypes. GCC accepts __restrict in
  both C and C++ modes, so the header remains usable from Chromium C++ without
  adding Linux-specific behavior or muting diagnostics.
