Crashpad's POSIX utility code had no TaterTOS handling for three platform

Fix:

  sysconf/getdtablesize/OPEN_MAX fallback, which TaterTOS libc provides.
- drop_privileges.cc uses TaterTOS setresgid/setresuid. TaterTOS is single-user

  because TaterTOS signal.h deliberately assigns the same POSIX subset values
  and keeps NSIG at 64.

Why:
These are real TaterTOS port gaps. TaterTOS should not require /proc to close
descriptors, should not fall through to unported Crashpad code, and should have
signal names matching its own signal.h constants.
