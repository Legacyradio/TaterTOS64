Fixed TaterTOS EGL platform typedef gap and GL display strictness fallbacks.

Blocker classification:
- third_party/angle/include/EGL/eglplatform.h: TaterTOS platform integration
  gap, not compiler strictness.
- ui/gl/gl_display.cc fallbacks: compiler strictness, not a TaterTOS API gap.

Why:
- ANGLE's eglplatform.h had no __tatertos__/__TATERTOS__ branch, so EGL native
  display, pixmap, and window types were undefined for the TaterTOS target.
- ui/gl/gl_display.cc had NOTREACHED-only default paths that GCC still treats
  as fallthrough or missing-return under -Werror.

Fix:
- Added a TaterTOS-specific EGL platform branch using void* for native display
  and khronos_uintptr_t for native pixmap/window handles.
- Added explicit fallback returns/breaks in GL display helper switches.
