What changed:
- Added packed-ramdisk seek support in src/kernel/fs/vfs.c and wired rd_ops.seek.
- Changed syscall exit teardown in src/kernel/proc/syscall.c from one global safe stack to per-CPU safe stacks.
- Disabled local interrupts before switching onto the exit teardown stack.
- Stored the Linux ELF entry value before freeing the temporary ELF image in src/kernel/proc/linux_elf.c.

Why:
- The first QEMU run proved LHELLO launched, but LFILE failed lseek(fd), LMMAP failed file-backed mmap, and the kernel later page-faulted.
- Root cause for lseek/mmap failure: ISO boot used the packed ramdisk backend, which had read/stat but no seek operation.
- Root cause for the post-probe panic: short-lived Linux processes can exit close together; a single shared exit stack can corrupt the saved kernel context.
- The Linux ELF loader also had a use-after-free style read of eh->e_entry after freeing the temporary ELF buffer.
