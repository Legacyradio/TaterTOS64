=====================================================================
fry1311 - devfs /dev/urandom unblock for real Claude startup
=====================================================================
DATE: 2026-06-03 18:55:10 CDT
GOAL: Crack the next Claude Code runtime blocker after the clean
fry1310 boot reached Bun/JSC and faulted at the 0xBBADBEEF crash site.

---------------------------------------------------------------------
DIAGNOSIS
---------------------------------------------------------------------
Offline disassembly of the real Claude binary at rip 0x60a9b84 showed
the crash site was not MAP_JIT yet. The failing path was:

  open(filename, O_RDONLY)
  if fd == -1 and errno != EINTR:
      write/deref 0xBBADBEEF
      ud2

The filename string at the referenced rodata address was:

  /dev/urandom

TaterTOS64v3 already had SYS_getrandom backed by entropy_getbytes(), but
the VFS had no /dev mount and no /dev/urandom node. libuv/Bun therefore
opened /dev/urandom directly, got ENOENT, and intentionally crashed.

---------------------------------------------------------------------
FIX
---------------------------------------------------------------------
Added a small VFS-backed devfs:

  src/kernel/fs/devfs.h
  src/kernel/fs/devfs.c

Nodes implemented:

  /dev/null    read EOF, write discards
  /dev/zero    read zero-filled bytes, write discards
  /dev/random  read entropy_getbytes()
  /dev/urandom read entropy_getbytes()

WHY:
  Claude's immediate blocker was /dev/urandom. Adding devfs at the VFS
  layer is the correct OS-side fix because other Linux runtimes also
  probe /dev/null, /dev/zero, /dev/random, and /dev/urandom. This avoids
  special-casing openat() and keeps the behavior available to every
  process.

Wiring:
  - Makefile now includes src/kernel/fs/devfs.o in KERNEL_OBJS.
  - src/kernel/fs/vfs.c mounts devfs at /dev after each successful root
    mount path: packed ramdisk, ToTFS GPT, ToTFS raw fallback, FAT32.
  - src/kernel/selftest.c now opens and reads /dev/urandom, /dev/zero,
    and /dev/null so this does not silently regress.

No Linux/Windows code was imported. This is native TaterTOS64v3 VFS code
backed by the existing entropy subsystem.
