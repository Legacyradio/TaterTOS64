Fry 1318 - trace-proven Tater Bridge syscall surface added

What changed:
- Added Linux syscall numbers in src/kernel/proc/linux_compat.h:
  gettimeofday(96), sysinfo(99), prctl(157), close_range(436).
- Added native Tater Bridge implementations in src/kernel/proc/syscall.c:
  - gettimeofday: RTC epoch + HPET uptime, timeval/timezone layout.
  - sysinfo: uptime, RAM totals, free RAM, process count, mem_unit.
  - prctl: SET/GET_NAME, dumpable, no_new_privs, THP disable, timer slack,
    seccomp query, pdeathsig, ptracer, and PR_SET_VMA naming as no-op success.
  - sched_getaffinity: returns the active SMP CPU mask.
  - close_range: closes Linux fd range or accepts CLOEXEC/UNSHARE as local no-ops.
  - tgkill: validates tgid/tid and treats fatal self-signals as group termination.

Why:
- Fry 1317 showed Claude got past /dev/urandom, sparse mmap, clone3, futex,
  epoll, timerfd, eventfd, and libuv setup, then entered glibc abort().
- The trace immediately before abort still had ENOSYS from time/sysinfo/prctl/
  sched_getaffinity/close_range/tgkill-class paths.
- These implementations are TaterTOS64v3 ABI translations, not imported Linux
  kernel code.
