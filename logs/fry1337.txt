fry1337 - Tater Bridge fcntl duplicate-stdio fix
Timestamp: 2026-06-04 10:22:13 CDT

What changed:
- Added FD_STDIO as a Tater Bridge fd kind for descriptors that are duplicates
  of stdin/stdout/stderr.
- Added helpers to duplicate an fd at or above a requested minimum while
  preserving Tater Bridge fd metadata and pipe refcounts.
- Implemented Linux fcntl command 0 / F_DUPFD and command 1030 /
  F_DUPFD_CLOEXEC.
- Routed duplicated stdout/stderr fds through the same Linux write path as fd 1
  and fd 2.
- Made duplicated stdio fds report as character devices for Linux fstat/poll.
- Updated Linux dup() to use the shared helper and allowed dup2() sources to be
  stdio descriptors.

Why:
