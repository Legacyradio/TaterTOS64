fry1356 - int3→SIGSEGV fallback added; getdents64 verified; Bun advances to new crash

Date: 2026-06-04 ~22:05 CDT

What changed:
- Added #BP→SIGTRAP→SIGSEGV fallback in lx_deliver_signal_from_exception.
  When vector 3 (#BP/int3) maps to SIGTRAP (sig=5) and no SIGTRAP handler
  is installed, the code now tries SIGSEGV (sig=11) before killing the
  process. This allows runtimes like Bun that install SIGSEGV but not
  SIGTRAP to catch assertion traps.

Why:
- fry1355 showed stable int3 blocker at 0x60EA0A7 (Bun assertion code
  0x1BC) with no SIGTRAP handler. Earlier boots got further by routing
  int3 differently. The fallback ensures Bun's crash reporter catches
  assertion traps and produces diagnostics.

- make src/kernel/proc/syscall.o: passed (pre-existing warning only)
- make kernel: passed
- Full staged build_iso.sh with STAGE_CLAUDE=1: passed
