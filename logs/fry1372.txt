Date: 2026-06-05 13:21 CDT

What changed:
- Fixed Linux sched_getaffinity return semantics in Tater Bridge.
  The old code returned the caller's cpusetsize. Linux returns the kernel
  affinity mask byte count. Host Claude sees return value 8, so Tater Bridge
  now returns an 8-byte rounded mask for <=64 CPUs instead of values such as
  128 when the caller supplies a large buffer.

- Closed a real futex wait race in sched_block_futex.
  The old path checked the futex word before publishing the waiter, then
  exposed a gap where another thread could change the word and call wake
  before the waiter was visible. The scheduler now rechecks the user word
  after setting wait_futex_key/wait_futex_bitset. If the word already changed,
  it cancels the wait and returns -EAGAIN, matching Linux's atomic
  compare-and-block shape more closely.
