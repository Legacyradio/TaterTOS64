====

- syscall.c struct netlink_cb {nl_pid, bound, used, rx_len, rx[128]} +
  wire constants (LNX_AF_NETLINK=16, RTM_GETADDR=22, RTM_NEWADDR=20,
  NLMSG_DONE=3, NLMSG_ERROR=2, NLM_F_MULTI, IFA_LOCAL=2, MSG_TRUNC).
- LNX_socket: domain==16 + proto==NETLINK_ROUTE(0) + type RAW/DGRAM ->
  lx_netlink_create_fd() (honors SOCK_NONBLOCK/CLOEXEC; autobind
  nl_pid=cur->pid). Other domains keep the EAFNOSUPPORT path.
- LNX_bind: sockaddr_nl accepted; nl_pid=0 keeps the autobind pid
  (glibc binds 0 then getsockname's the assigned pid).
- LNX_getsockname: FD_NETLINK branch returns sockaddr_nl{16,0,nl_pid,0},
  value-result addrlen=12.
- send side (LNX_sendto + LNX_sendmsg gather + lx_write_fd):
  lx_netlink_handle_send(): RTM_GETADDR -> reply built synchronously
  into cb->rx: RTM_NEWADDR (nlmsghdr 16 + ifaddrmsg{AF_INET,
  prefixlen=popcount(netmask), scope=0, index=2} 8 + rtattr IFA_LOCAL
  + IPv4 net-order 8) = 32 bytes, then NLMSG_DONE+int32(0) = 20 bytes;
  both stamped with the REQUEST's nlmsg_seq and the socket's nl_pid
  (glibc's match rules: sender nl_pid==0, nlmsg_pid==bound pid,
  nlmsg_seq==req seq — all satisfied). Address source: net_get_config()
  (DHCP'd e1000, host byte order -> emitted big-endian). If DHCP not up:
  DONE-only reply (no addresses). Non-GETADDR types: NLMSG_ERROR ack
  err=0 echoing the request header. Returns full request length.
- recv side (lx_netlink_recvmsg for LNX_recvmsg + LNX_recvfrom branch +
  lx_read_fd): drains the buffered datagram across iovecs, fills sender
  sockaddr_nl{16,0,pid=0(kernel),0}, writes back value-result
  msg_namelen (off 8) and msg_flags (off 48, MSG_TRUNC if short).
- poll_check_fd FD_NETLINK: POLLIN when rx_len>0, POLLOUT always.
- lx_close_fd FD_NETLINK: kfree. LNX_setsockopt on netlink: accept+
  ignore (same policy as the AF_INET option shim).
- NEW BEACON: LXNL req/rx (kprint_serial_only) — ADD TO STRIP LIST with
