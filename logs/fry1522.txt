Finding 3 - The exit is downstream of INPUT, not the TTY identity check:
  Exit trace (serial ~line 14565):
    TBREAD pread64 fd=11 len=256 off=0 -> 37
    TBIOCTL pid=14 fd=0 cmd=402c542b      <- TCSETS2 (_IOW('T',0x2b,termios2),44B)
    TBIOCTL pid=14 fd=0 cmd=402c542b
    TBIOCTL pid=14 fd=1 cmd=402c542b
    TBIOCTL pid=14 fd=2 cmd=402c542b
    TBEXIT group pid=14 tgid=14 code=129
  The TCSETS2 on fds 0/1/2 immediately before exit is the standard
  terminal-restore-on-exit cleanup. Claude reached the prompt, waited for a
  keypress, and stdin (fd0) returned EOF because the keyboard is not wired to the
  child's stdin. The interactive prompt cannot read input -> Claude restores
  terminal modes and exits 129 (128+1 = SIGHUP/hangup convention, consistent with a
  stdin that EOFs being treated as a terminal hangup).
  Earlier thread exit also seen: TBEXIT thread pid=25 tgid=14 code=0 (worker).

Confirmed root cause:
  Interactivity is blocked by MISSING READABLE STDIN, not by the isatty/ENOTTY or
  missing-/dev/tty failures. Claude pressed past those far enough to fully render
  the trust prompt. With fd0 at EOF (keyboard unwired), the prompt EOFs and Claude
  exits.

Correction to fry1521:
  fry1521's "exited at the TTY check" claim is retracted. The ENOTTY (ioctl -25) and
  /dev/tty ENOENT failures are real but were NOT the proximate exit cause. The
  proximate cause is EOF on stdin at the interactive prompt.

Implication for the build sequence (matches user's reordering):
  - E (async spawn + master pump) is the prerequisite substrate: a synchronous
    spawn blocks the Shell UI thread, so nothing can pump a master fd to feed stdin
    or observe child output. Build E first.
  - B (keyboard -> child stdin) is the actual gate to interactivity. Once stdin
    delivers keypresses, the trust prompt can be answered.
  - The fb transposition garble is tracked as a SEPARATE concurrency bug, not part
    of the VT parser work (C).
  - A (PTY identity: /dev/tty + termios ioctls) is still required for full
    correctness but is not the immediate blocker to first interaction.
