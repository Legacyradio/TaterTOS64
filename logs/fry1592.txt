WHY (Rule 6) — Zack's (correct) point: "we already had it working; we were only supposed to add tools; why did
that stop typing input?" Truth: the changes did NOT break input (serial identical: 92 keys delivered, read(fd0)=1,

FIX (src/kernel/proc/syscall.c)
1. lx_try_demand_page: after committing the faulting page, commit up to LX_DEMAND_BATCH(=16)-1 FOLLOWING pages in the
   SAME vm_region (skip already-mapped; stop at region end / on OOM). A large sequential zero now costs ~1 fault per
   64KB instead of per 4KB -> ~16x fewer #PF -> the page-in is fast -> typing responsive + busybox/tools load fast.
   Bounded by the region, so sparse cages are not over-committed beyond the touched run.
2. lx_redirect_tool_path (fry1588): added an early prefix gate -> only /bin/, /sbin/, /usr/bin/ paths do the vfs_stat
   redirect; every other open returns immediately. Removes any per-open overhead on the openat storm.
