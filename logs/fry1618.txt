WHAT HAPPENED
---------------------------------------------------------------------------------
ERRORS:
  perf_jit_trampoline.c:1267:20: error: implicit declaration of function 'syscall'
  perf_jit_trampoline.c:1267:28: error: 'SYS_gettid' undeclared

---------------------------------------------------------------------------------
ROOT CAUSE
---------------------------------------------------------------------------------
The perf JIT trampoline is a Linux-specific feature that writes JIT code
metadata to a special file (/proc/self/perf_event_paranoid) so the Linux
perf tool can profile Python JIT-compiled code. It uses:
  - syscall(SYS_gettid) — raw Linux syscall to get thread ID
  - Linux perf event structures
  - /proc filesystem access

TaterTOS has none of these. The feature is meaningless on TaterTOS:
  - No /proc filesystem
  - No perf tool
  - No syscall() wrapper (TaterTOS uses direct fry_* functions)
  - No SYS_gettid (TaterTOS has SYS_GETTID but different ABI)

The pyconfig.h had PY_HAVE_PERF_TRAMPOLINE defined from the host Linux probe.

---------------------------------------------------------------------------------
FIX
---------------------------------------------------------------------------------
Changed pyconfig_tater.h:
  PY_HAVE_PERF_TRAMPOLINE — #define 1 → #undef

WHY: The perf trampoline is a Linux kernel profiling feature. TaterTOS
doesn't have the perf subsystem, /proc filesystem, or raw syscall() ABI.
Disabling it is the correct fix — CPython compiles perf_jit_trampoline.c
as an empty file when PY_HAVE_PERF_TRAMPOLINE is not defined (the entire
file body is inside #ifdef PY_HAVE_PERF_TRAMPOLINE).

This is not a shortcut — the feature genuinely doesn't apply to TaterTOS.
Implementing syscall() and SYS_gettid would just be adding stubs for a
feature that can never work without the Linux perf subsystem.

Copied updated pyconfig_tater.h to pyconfig.h.
