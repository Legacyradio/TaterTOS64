---------------------------------------------------------------------------------
WHAT WE BUILT
---------------------------------------------------------------------------------
176 CPython source files compiled into a single freestanding ELF binary:

  Python/     — ~95 files (interpreter core, excluding dynload_*, emscripten_*)
  Objects/    — ~45 files (object types, excluding obmalloc for now but mimalloc included)
  Parser/     — ~15 files (PEG parser, tokenizer, lexer)
  Modules/    — ~35 files (posix, socket, io, abc, codecs, errno, gc, itertools,
                 math, operator, sre, struct, _json, _pickle, array, thread,
                 signal, time, weakref, functools, suggestions, datetime,
                 collections, types, typing, locale, opcode, stat, pwd,
                 symtable, tracemalloc, atexit, getbuildinfo)
  Programs/   — python.c (entry point)

Excluded:
  _ssl — needs BearSSL (Phase 3)
  faulthandler — GCC 16 compatibility issue
  bytecodes.c / optimizer_bytecodes.c — generated files needing build tools
  dynload_* — not needed (static linking)

---------------------------------------------------------------------------------
KNOWN LIMITATIONS
---------------------------------------------------------------------------------
1. No stdlib — Python will start but won't find any .py files.
   Need to install CPython's Lib/ to sysroot/usr/local/lib/python3.14/

2. No _ssl — Phase 3 will add BearSSL backend.

3. No getrandom — uses stub (zeros). Phase 3 can hook fry_random.

4. faulthandler module not compiled — GCC 16 Py_ARRAY_LENGTH issue.

5. bytecodes.c / optimizer_bytecodes.c not compiled — need generated headers
   from CPython's build tools. These are for JIT specialization; basic
   interpreter works fine without them.

6. Many gap stubs are true stubs (return 0) — fine for single-user OS
   but some operations (waitid, posix_spawnattr_*) will fail silently.
