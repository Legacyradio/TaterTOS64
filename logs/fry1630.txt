---------------------------------------------------------------------------------
TATEROS BOOT PROCEDURE
---------------------------------------------------------------------------------
1. Build TaterTOS64v3 kernel + ToTFS image
2. Copy python3.fry to TaterTOS apps directory
3. Mount ToTFS on /mnt/totfs
4. Copy sysroot/usr/ → /usr/, sysroot/opt/ → /opt/
5. Launch TaterTOS shell
6. python3 /opt/hermes-agent/tatertos_bootstrap.py
7. Set OPENAI_API_KEY in environment
8. python3 /opt/hermes-agent/run_agent.py --provider openai "Hello!"
