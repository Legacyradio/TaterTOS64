---------------------------------------------------------------------------------
OBJECTIVE
---------------------------------------------------------------------------------
Create the on-device development cycle for Hermes Agent on TaterTOS64v3.
"Self-hosting" means TaterTOS can modify and rebuild its own software.

Two-track approach:
  A. Python native compiler — .py → bytecode (import-time compilation)
  B. Host cross-compiler — for C changes (libc, new modules, Python rebuild)

---------------------------------------------------------------------------------
APPROACH
---------------------------------------------------------------------------------

TRACK A: PYTHON NATIVE COMPILER
  Python IS the compiler. On import, Python compiles .py → .pyc bytecode.
  No external compiler needed. Hermes can modify its own source and restart.

  Created: hermes_autobuild.py
    --check    Validate all Hermes imports
    --reload   Hot-reload modified modules  
    --daemon   Watch for file changes, auto-reload

  This provides:
    ✓ Edit Hermes Python source on TaterTOS
    ✓ Validate syntax + imports
    ✓ Hot-reload changed modules without restart
    ✓ Daemon mode for continuous development

TRACK B: HOST CROSS-COMPILER
  For changes to TaterTOS libc, CPython, or C extension modules:

  make -f Python3.mk python3   → rebuilds python3.fry
  Copy python3.fry to TaterTOS  → deploy new binary

  Also available: TCC compilation attempted but blocked by ELF header
  conflicts between TaterTOS elf.h and TCC's internal elf.h. TCC can be
  added later by resolving these conflicts or using a pre-built binary.

---------------------------------------------------------------------------------
DEVELOPMENT WORKFLOW
---------------------------------------------------------------------------------

Pure Python changes (most Hermes code):
  1. Edit /opt/hermes-agent/*.py on TaterTOS (vim, ed, or Hermes file tools)
  2. python3 /opt/hermes-agent/hermes_autobuild.py --check
  3. python3 /opt/hermes-agent/hermes_autobuild.py --reload
  4. Hermes Agent restarts with new code

C changes (libc, new C extensions):
  1. Edit on host Linux
  2. make -f Python3.mk python3
  3. Copy python3.fry to TaterTOS
  4. Reboot or reload

Full rebuild (everything):
  1. On host: make -f Python3.mk pyclean && make -f Python3.mk python3
  2. Copy python3.fry + sysroot/* to TaterTOS
  3. Reboot
