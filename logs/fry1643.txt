PROBLEM CHAIN (each peeled):
- After staging busybox at /bin/sh (fry1642), busybox LOADED but Bash still "broken".
- Cause 1: busybox sh called legacy fork(2) (nr=57) -> UNIMPLEMENTED. (vfork/nr=58 was
  implemented; fork was not.)
- Cause 2 (the real one): Claude Code's Bash tool PROBES `bash --version` at /bin/bash,
  /usr/bin/bash, /usr/local/bin/bash, /opt/homebrew/bin/bash and REQUIRES real bash.
  busybox has sh/ash but NO bash applet -> all probes ENOENT -> "no POSIX shell". So
  busybox-as-/bin/sh can never satisfy the Bash tool. Zack's instinct (bash != busybox)
  was correct.

FIX 1 - fork routing (src/kernel/proc/syscall.c):
- Added `case LNX_fork:` falling through to the existing `case LNX_vfork:` handler, +
  `case LNX_fork: return "fork";` in the name table. fork now gets vfork semantics
  (child returns 0, execs immediately; parent suspended until child execs/exits) -- the
  fork+exec pattern shells use. Compiles clean.
- LIMIT: this is NOT concurrent COW fork. Sequential command lists (cmd && cmd) work;
  shell PIPELINES (a | b, which need both processes live at once) do NOT. True fork is
  a separate, larger kernel item (see OPEN).

FIX 2 - static bash:
- No static bash on Garuda (Arch-based); its bash is dynamic. Built one from source:
  ~/bash-static-build/bash-5.2, `./configure --enable-static-link --without-bash-malloc
  --disable-readline --disable-history CFLAGS="-O2 -std=gnu17"` then make.
  - -std=gnu17 needed: gcc 16 defaults to C23 where K&R `()` decls mean (void) ->
    bash 5.2 fails with "too many arguments". gnu17 restores unspecified-args.
  - --disable-readline/-history dropped the libtinfo.a dependency (no static ncurses on
    Arch). Fine: Claude runs `bash -c`, non-interactive, no line editing needed.
  - Result: ELF x86-64 STATICALLY LINKED, 2.16MB stripped. `bash --version` + `bash -c`
    (substitution, vars) verified on host.
- Saved to ~/tatertos-shell/bash; staged to ToTFS /bin/bash (kernel redirects /bin/* ->
  /nvme ToTFS, fry1588). build_iso.sh now stages it (BASH_STATIC_BIN, default
  ~/tatertos-shell/bash), alongside busybox /bin/sh (LINUX_SHELL_BIN) + the auth files.
