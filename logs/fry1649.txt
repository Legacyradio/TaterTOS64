# fry1649 - Fix xterm layout parser regression after color verification
Timestamp: 2026-06-19 15:08:24 CDT
Type: terminal parser/layout fix
Files changed:
  - src/user/shell/shell.c

What changed:
  - Fixed carriage return handling: '\r' now returns to column 0 instead of being ignored.
  - Added row copy/blank helpers that preserve foreground/background attributes.
  - Added xterm CSI layout operations commonly used after TERM=xterm-256color:
      C/a cursor forward, E/e next line, L insert lines, M delete lines,
      S scroll up, T scroll down.

Why:
  - Color was confirmed working, but layout was broken. TERM=xterm-256color made Claude
    emit richer terminal layout controls. Ignoring carriage returns and line
    insert/delete/scroll controls could make the TUI overwrite or drift into wrong rows
    and columns.
