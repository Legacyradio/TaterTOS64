ROOT CAUSE: CPython init_sys_streams builds sys.std{in,out,err} via _io.FileIO(fd)
  which calls fstat(fd). CPython fileio.c:471-481 treats EBADF from fstat on a
  std fd as fatal -> the stream is left None. The kernel SYS_FSTAT (syscall.c
  case 91, line 10745) does `if (fd < 3 ...) return -EBADF;` — it ONLY stats
  regular files and rejects fds 0/1/2. So every std stream came back None ->
  print() silent no-op, tracebacks vanish. This is the real cause of "hermes
  runs but no output".
