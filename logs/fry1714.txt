  - The REAL Claude Code is the Linux binary /nvme/RCLAUDE.LXE (shell.c:1028

    CLAUDE_BIN set (build_iso.sh:437). It lives ONLY on the nvme (too big for the
    ramdisk, ~223MB).
  - I ran build_iso.sh TWICE for the hermes work (08:52, 08:54) WITHOUT
    STAGE_CLAUDE=1 / CLAUDE_BIN. Both reformatted the nvme and did NOT re-stage
    RCLAUDE.LXE. -> /nvme/RCLAUDE.LXE gone -> `claude` => "launch failed (Is
    STAGE_CLAUDE=1 in the image?)".
  - NOT caused by my elf.c/libc.c edits: RCLAUDE.LXE is a Linux glibc binary loaded
    by the linux-compat path (NOT elf_load_fry, NOT our libc). claude.fry (313KB
    native launcher) was relinked at 08:54 by build_iso's `make ... claude` (l.300)
    but that is not the binary that runs.
