=== 2. THE INSTRUMENTATION (diagnostic only) ===
Global budget `int g_tlsdbg_budget = 96;` (process.c) caps TOTAL TLSDBG lines so
a ~1.2M-tick agent import cannot drown the serial log. Every site decrements it.
All lines are greppable by the single prefix `TLSDBG`.

  src/kernel/proc/process.c
    process_build_thread_tls() early-out ->
      "TLSDBG build tid=%u NO_PT_TLS early_out fs=0 has_tls=%u memsz=%lu"
    process_build_thread_tls() success ->
      "TLSDBG build tid=%u OK fs=%lx bbase=%lx alloc=%lu next=%lx"
    process_create_user_thread() ->
      "TLSDBG spawn path=NATIVE tid=%u parent=%u fs=%lx entry=%lx"
    process_clone_linux_thread() ->
      "TLSDBG spawn path=LINUX_CLONE tid=%u parent=%u fs=%lx(from clone arg) rip=%lx"

  src/kernel/proc/syscall.c
    SYS_GET_TLS_BASE -> "TLSDBG get tid=%u tgid=%u fs=%lx"
    SYS_SET_TLS_BASE -> "TLSDBG set tid=%u old_fs=%lx new_fs=%lx"
  (SYS_SET was added because a thread OVERWRITING its own %fs after the kernel
   built one would silently undo fry1790 — that possibility was untested.)
