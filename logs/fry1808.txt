=== TWO BUILD FAILURES HIT AND FIXED (recorded so they are not re-hit) ===
FAILURE 1: compiling expat with CPYTHON_CFLAGS gave
    <command-line>: error: expected identifier or '(' before string constant
    xmlparse.c:3775: 'ELEMENT_TYPE' has no member named 'nDefaultAtts'
  CAUSE: CPython's build defines -DVERSION='"3.14"' and -DPREFIX='"/usr/local"'
  (plus EXEC_PREFIX/ABIFLAGS/VPATH/PLATLIBDIR). Those names collide with ordinary
  identifiers inside libexpat, so the preprocessor substituted string literals
  into expat's own code. libexpat is THIRD-PARTY and must not inherit CPython's
  build defines.
FAILURE 2: compiling expat with bare UFLAGS gave
    expat_config.h:8: fatal error: pyconfig.h: No such file or directory
  CAUSE: this CPython-bundled expat_config.h #includes pyconfig.h, so expat DOES
  need CPython's include PATHS.
RESOLUTION — EXPAT_CFLAGS keeps the paths, drops the string defines:
    EXPAT_CFLAGS = $(UFLAGS) -ffunction-sections -fdata-sections -DPy_BUILD_CORE
                   $(EXPAT_DEFS) $(EXPAT_INC)
                   -I$(CPYTHON_DIR) -I$(CPYTHON_DIR)/Include
                   -I$(CPYTHON_DIR)/Include/internal -I$(CPYTHON_DIR)/Modules
                   -Wno-unused-parameter -Wno-unused-function
                   -Wno-missing-field-initializers
  pyexpat.c is different — it is CPython glue and DOES get CPYTHON_CFLAGS.
NOTE: expat_config.h already sets XML_POOR_ENTROPY=1 and #undefs HAVE_GETRANDOM /
HAVE_ARC4RANDOM, i.e. it is pre-configured for a system with no /dev/urandom and
no getrandom — exactly TaterTOS. No entropy work was needed.
