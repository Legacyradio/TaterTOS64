=== OPEN — MOST LIKELY CAUSE OF THE SILENCE (found, NOT yet tested) ===
The agent's user config/credentials directory is NOT staged onto the image.
  Host has BOTH:
    ~/hermes-agent/.env                    <-- IS staged (present in sysroot)
    ~/.hermes/{auth.json, auth.lock, config.yaml, cache, bin, cron, ...}

  hermes reads user config from $HOME/.hermes; in TaterTOS HOME=/nvme

waiting rather than print. THIS IS A HYPOTHESIS — it has NOT been tested and no
credential was staged this step. Deliberately stopping here rather than guessing
further, and note staging real API credentials into an image is Zack's call, not
