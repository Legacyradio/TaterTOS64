    - Added -Wno-alloc-size-larger-than, -Wno-array-bounds to cflags.
      GCC 15 warns about these inside libc++ headers (e.g. vector.h
      array-subscript, allocate.h size validation). These are false
      positives from Chromium's specific usage patterns — libc++ is
      correct, GCC is being too strict. Suppress them.

  base/strings/utf_ostream_operators.cc
    - Changed three wchar_t operator<< definitions from function-style
      (std::operator<<(...) { ... }) to namespace-block style
      (namespace std { ostream& operator<<(...) { ... } }).
      Reason: libc++ uses inline namespace __Cr inside std, and GCC 15
      enforces that operator overloads for std::__Cr types must be
      defined inside the enclosing namespace, not as qualified
      out-of-line definitions.
